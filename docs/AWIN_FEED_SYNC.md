# Awin incremental feed synchronization

Owner-only `/admin/imports/awin/sync` accepts an authorized, one-advertiser legacy CSV up to 100 rows/100 KB. Database validates scope, price, URL and row bounds. New rows enter the existing private queue atomically. Existing active IDs are compared against the staged candidate or converted offer; missing rows are not interpreted as stock changes. Price/link proposals are reviewed individually and applying them invalidates verification and creates an offer in draft status; no product copy/image overwrite. Metadata comparison uses original candidate, not current editorial copy; compare the original export manually. Newer observations and changed offer baselines prevent stale application. Reports and decisions are owner-only. No live API, credential storage, schedule, availability claims or real affiliate records. Repeated staged changes require manual rejection/reimport if needed. First version recent 25 comparisons, 100 items/run; direct run ID lookup. Browser and real feed acceptance remain outstanding.
