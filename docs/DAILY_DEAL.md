# Daily Deal V1
Homepage and Holidays show one owner-attested promotion for current UTC day only, else deterministic daily rotation among the latest 100 eligible priced USD general catalog offers, one per product. No fake discounts, reference prices, demand rankings, timers or stock claims. Owner-only scheduling at /admin/deals/daily (today through +7 UTC days, actual promotion window no longer than offer verification, private evidence note, one unrevoked record per day, explicit revoke). Public narrow RPC checks offer/product/merchant versions, dependencies, source authorization and windows atomically; evidence stays private. Browser checks expiry/day every 30s, refreshes on focus/day change, existing outbound route rechecks eligibility. Fallback changes if eligible pool changes; not guaranteed daily novelty for small catalogs. No external requests or paid model. Amazon editorial excluded. Actual commercial rights/evidence and browser acceptance remain launch gates. Migration 030 and synthetic tests require verification.
