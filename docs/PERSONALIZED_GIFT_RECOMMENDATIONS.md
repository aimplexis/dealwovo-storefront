# Personalized gift recommendations V1
Gift Finder loads the existing anonymous, RLS-protected latest 100 general catalog offers, with no raw affiliate destination in the client. Recipient and occasion are ranking preferences, not guaranteed suitability; explicit catalog phrases provide evidence. Selected interest uses exact normalized category aliases, and budget enforces strict USD intervals (under $25/$50, inclusive $50–150, over $150). Unknown prices excluded for bounded budget. All-interest recommendations require gift-related text. No inferred demographics or suitability, no paid AI, no stored shopping profile. Expired offers removed on clock refresh, outbound links recheck eligibility. One match per product, up to 12 displayed, compare up to four offers. Editorial ideas remain separately labelled; no-match and unavailable states distinct. Amazon editorial links not included. Synthetic regression tests included; real catalog and visual browser acceptance pending. No database migration or production launch.
