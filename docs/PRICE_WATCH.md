# Price Watch V1
Automatic private observations on eligible verified offer writes; existing eligible approvals seeded as a single baseline. No external fetch or invented history. Public narrow RPC compares current and immediately preceding verified observations within 90 days, same offer/product/retailer/link/currency fingerprint, positive USD price, current approval and dependencies; same-time ambiguity and missing evidence suppress comparison. Only price pairs returned, not private identity or destinations. Wishlist target stored in existing local saved product entry; removed with product/clear. In-app messages at wishlist load, focus and manual refresh; no persistent notification inbox, email/push, background browser work or user accounts. Current offers capped at three per product. No live stock guarantee or discount claim. Future opt-in email requires verified sender and consent/unsubscribe controls. Migration and actual catalog acceptance required.
